- Python 3.x

## 🚀 Getting Started

Clone this repository:

```bash
git clone https://github.com/saiganesh-A261/CN_LAB.git
```

Navigate to the project directory:

```bash
cd CN_LAB
```

Open the experiment files inside the `CN-LAB-main` folder.

To run a Python program, use:

```bash
python ex1.py
```

For Tcl scripts and Wireshark exercises, use the appropriate simulation environment or packet analysis tool.
